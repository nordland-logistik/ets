# Nordland Logistik Website

Fertige statische Website für die virtuelle ETS2-/SpedV-Spedition Nordland Logistik.

## Dateien
- `index.html` – komplette Website
- `style.css` – Design und responsive Darstellung
- `script.js` – mobiles Menü + Discord-Link

## Discord-Link eintragen
Öffne `script.js` und ersetze:

https://discord.gg/DEIN-LINK-HIER

durch euren echten Discord-Einladungslink.

## Online stellen
Die Website benötigt keinen Server und keine Datenbank. Du kannst den kompletten Ordner bei einem statischen Hosting-Anbieter hochladen.

Die beiden Hintergrundbilder kommen aktuell von Unsplash. Wenn du eigene Nordland-LKW-Bilder hast, kannst du die beiden `background:`-URLs in `style.css` durch lokale Bilddateien ersetzen.
